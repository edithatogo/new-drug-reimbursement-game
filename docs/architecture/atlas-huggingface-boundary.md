# Atlas and Hugging Face publication boundary

Reimbursement Atlas remains authoritative for acquisition, provenance,
transformations, source terms, and approval. The application emits a SHA-256
receipt for a validated approved-derived packet; it never downloads or embeds
raw source payloads.

Publication contracts are limited to owner-controlled Hugging Face IDs under
`edithatogo/`. Dataset and Space licences are validated separately because
source-specific derived-data terms can differ from software terms. A contract
is not an upload and does not authorize publication.
