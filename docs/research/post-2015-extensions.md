# Post-2015 extension boundary

`research_extensions.py` makes four synthesis implications executable as
research-only state:

- distributional equity keeps subgroup contributions and normalized weights;
- managed entry settles price, rebate, monitoring, clawback, and termination;
- adaptive evidence compares a Voiage-supplied information value with a caller
  threshold without calculating VOI locally;
- portfolio spillovers keep local and global value separate with a payer share.

These are explicit extensions, not Pekarsky source-equation conformance or
empirical calibration. Kairos owns event time and Voiage owns VOI methods;
Atlas owns evidence and provenance.
