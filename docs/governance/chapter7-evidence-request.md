# Chapter 7 evidence request

This is the smallest evidence package needed to close the Chapter 7 gate
without copying the source book into the repository.

## Required source evidence

Provide, from an authorized copy of Pekarsky (2015):

1. Edition and publication metadata, plus the exact page numbers for equations
   7.2–7.5 and the surrounding technical-efficiency definition.
2. A short reviewer-authored paraphrase of what the technical-efficiency
   parameter means, what its sign/order restrictions are, and which quantities
   it changes. Do not commit a scan or a lengthy source excerpt.
3. A precise mapping decision: whether the source parameter maps to `g*`, to a
   different productivity term, or to a named alternative that must remain
   unresolved.
4. A checksum or stable identifier for the reviewed source artifact, retained
   outside this repository if the source terms prohibit redistribution.

## Required independent review receipt

The reviewer should record identity/role, date, reviewed repository revision,
source edition/pages, equations checked, dimensional conclusion, mapping
decision, disagreements, and an explicit disposition (`accepted`, `conditional`,
or `rejected`).
