# Changelog

## 0.4.0

- Added a bundle-first Codex handoff that preserves Git history and tags.
- Added an internal repository activation prompt for GitHub remote creation,
  ecosystem-clone resolution, Conductor activation, and autonomous execution.
- Added dependency-free discovery of pinned UOGTO, Kairos, Voiage, and
  Reimbursement Atlas checkouts with ignored local and portable tracked reports.
- Added baseline GitHub Actions CI, Dependabot, CODEOWNERS, and Conductor tracks.


## 0.3.0 — 2026-07-20

- Replaced third-party-capability-first architecture with an ecosystem-first
  design centered on UOGTO, Kairos, Voiage, and Reimbursement Atlas.
- Separated the reimbursement application from a domain-neutral Rust game
  capability incubator.
- Removed third-party game/health-economic frameworks from runtime design.
- Restricted Hugging Face manifests to `edithatogo/*`.
- Added UOGTO extension proposals, ecosystem pins, migration ledger, research
  synthesis, gap map, and upstream handoff packets.
- Added a clean-room Python PEA implementation, Rust solver seed, tests, and
  comprehensive Codex prompts.
