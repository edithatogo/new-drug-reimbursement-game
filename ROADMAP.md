# Roadmap

## Phase 0 — architecture and clean-room kernel (implemented)

- ecosystem-first ports and dependency policy;
- PEA equations and invariants;
- UOGTO extension seed;
- Rust game-core and backward-induction seed;
- synthetic examples and validation.

## Phase 1 — general Rust game runtime

- canonical schema and JSON-LD import/export;
- pure-strategy normal-form support;
- information sets and behavioural strategies;
- solver trait registry and diagnostics;
- Kairos execution compiler and trace model;
- generated Python bindings.

## Phase 2 — upstream ontology and ecosystem contracts

- UOGTO applied pack PR;
- Voiage conformance adapter;
- Reimbursement Atlas PEA-derived view;
- Kairos event-contract integration;
- licence metadata reconciliation.

## Phase 3 — full Game 1 reconstruction

- continuous/discrete price spaces;
- production costs and demand;
- bargaining variants and threshold disclosure;
- confidential rebate and contract variants;
- analytic and computational equivalence tests.

## Phase 4 — Games 2 and 3

- capital market and incomplete information;
- R&D success/failure and borrowing;
- multi-period premium model;
- global spillovers and contract alternatives;
- Voiage structural/sequential uncertainty.

## Phase 5 — post-2015 extensions

- distributional/equity payoff vectors;
- indication/subgroup/lifecycle pricing;
- managed entry and evidence development;
- repeated/multi-payer games;
- capacity and implementation through Kairos;
- empirical calibration from approved Atlas records.

## Phase 6 — extraction and release

- extract domain-neutral crates to a dedicated Rust repository;
- replace the Python oracle in the application runtime;
- publish bindings and conformance package;
- independent economic, ontology, security, legal, and reproducibility review.
