# Workflow

1. Restore and validate the repository from the signed/checksummed handoff.
2. Resolve the pinned owner-controlled ecosystem checkouts.
3. Establish a clean baseline and create a focused working branch.
4. Select the highest-priority unblocked track.
5. Record assumptions, tests, and evidence before changing status.
6. Implement in small commits and run the narrowest relevant checks continuously.
7. Run all repository quality gates before closing a milestone.
8. Update the status and run log with exact evidence, not estimates.

No track may bypass the clean-room, provenance, ecosystem ownership, or
application/capability-boundary constraints in `AGENTS.md`.
