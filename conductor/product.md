# Product definition

The project delivers an auditable new-drug reimbursement game application and
incubates a reusable, domain-neutral UOGTO-native Rust game runtime above Kairos.

Users are health-economics researchers, ontology and simulation developers, and
reviewers who need explicit assumptions, provenance, and reproducible results.

The project does not provide reimbursement recommendations, HTA submissions, or
regulator-grade validation. Voiage, Kairos, UOGTO, and Reimbursement Atlas retain
their capability ownership boundaries.
